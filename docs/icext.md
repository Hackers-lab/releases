# Image-Check Extension (icext)

Boost verification speed with quick-action observation buttons, hotkeys, auto-submissions, and a collapsible status tracker with live logs.

## How to Import / Install the Extension

Follow these steps to import the extension into Google Chrome or any Chromium-based web browser:

### Step 1: Download the Release

1. Under the latest release, download the `icext.zip` asset.

### Step 2: Extract the ZIP Archive
1. Locate the downloaded `icext.zip` on your computer.
2. Extract/unzip the file. You will see a folder named `icext` containing:
   - `manifest.json`
   - `content.js`

### Step 3: Enable Developer Mode in Chrome
1. Open Google Chrome.
2. Navigate to the extensions page by typing `chrome://extensions/` in the URL bar and pressing **Enter**.
3. In the top-right corner of the Extensions page, toggle the **Developer mode** switch to **ON**.

### Step 4: Load the Unpacked Extension
1. In the top-left corner of the Extensions page, click the **Load unpacked** button.
2. Select the extracted `icext` folder (the directory containing `manifest.json` and `content.js`).
3. The extension is now successfully installed and active!
