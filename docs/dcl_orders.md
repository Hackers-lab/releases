# WBSEDCL Orders

A modern desktop application to browse, search, and download the latest internal orders from WBSEDCL (West Bengal State Electricity Distribution Company Limited).

## What is This?

WBSEDCL Orders is a desktop application designed for employees to quickly access and download official order documents from your organization. Instead of navigating through web portals or emails, all orders are consolidated in one clean, easy-to-use interface.

## Features

✅ **Secure Login** — Employee ID-based authentication (8-digit ERP ID starting with 9)

✅ **Live Order Updates** — Automatically fetches the latest orders from the official WBSEDCL server

✅ **Auto-Refresh** — Orders refresh automatically every 5 minutes, so you never miss updates

✅ **Search Orders** — Quickly find orders by order number, title, or date

✅ **One-Click Download** — Download PDFs directly to your Downloads folder

✅ **Cached Storage** — Orders are saved locally for offline access

✅ **Modern UI** — Clean, professional interface designed for productivity

## How to Use

### 1. **First Time Setup**
   - Launch the application
   - Enter your ERP ID on the login screen (8 digits starting with 9)
   - Click "Login"

### 2. **Browse Orders**
   - After login, all orders appear in a table
   - Scroll through the list to view order numbers, titles, and dates
   - Each row shows one order

### 3. **Search for Specific Orders**
   - Use the search box at the top
   - Type any part of an order number, title, or date
   - Results filter automatically as you type

### 4. **Download an Order**
   - Click the "Download" button on any order row
   - Choose where to save the PDF file
   - The file downloads to your selected location

### 5. **Refresh Data**
   - Click the "Refresh Data" button to manually update orders from the server
   - The app shows status messages during refresh

### 6. **Auto-Refresh**
   - Orders automatically update every 5 minutes
   - You'll see a status message showing the last update time

## Troubleshooting

### App won't start
- Ensure you have Python 3.11 or later installed
- Check your internet connection

### Can't login
- Verify your ERP ID is exactly 8 digits and starts with 9
- Contact your HR department if you don't know your ERP ID

### Orders not loading
- Check your internet connection
- Click "Refresh Data" to manually fetch orders
- If the problem persists, restart the application

### Download failed
- Ensure you have write permission in your Downloads folder
- Check available disk space
- Verify internet connection is stable during download
